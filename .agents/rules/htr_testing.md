# HTR/OCR Testing Rules

When testing updates to the EyM Sanskrit OCR & Scholar's Workstation, always use a diverse matrix of manuscript media and scripts:

1. **Scripts**: Test both handwritten scripts (manuscript hands) and standard printed Devanagari scripts.
2. **Material Mediums**:
   - **Palm Leaf Samples**: Test palm leaf manuscripts (both incised/stylus and inked variants).
   - **Old Paper Manuscripts**: Test aged, degraded paper manuscripts (ink reed pen, bleed-through, foxing).
   - **Wood/Stone Carved Text**: If possible, test carved inscriptions (stone inscriptions, copper plates, or wood engravings).
