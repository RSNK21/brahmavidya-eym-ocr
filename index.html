About this prototype
A no-server preview of EyM: OCR runs with Tesseract.js (the engine + language data download from a CDN once, then work offline; self-host them for a fully offline deployment). Corrections teach a confusion matrix and sessions persist in IndexedDB on this device. Export/import uses the same .eym-matrix format as the desktop app for sharing across institutions. Transliteration (Devanagari → IAST) is built in. The Monier-Williams Sanskrit-English Dictionary (195K+ headwords) powers spell-checking and on-demand word lookup.
